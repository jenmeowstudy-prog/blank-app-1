# # 🌱 EcoTrack System

EcoTrack is a Streamlit-based web application designed to help schools track waste management, incentivize recycling through student points, and display real-time house leaderboards.

---

## 🚀 Features

* **Student Management:** Register, search, and remove student profiles (ID, Name, Grade, Section, House).
* **Waste Logging:** Record waste collection entries and calculate points earned.
* **Leaderboards & Analytics:** View overall house totals, individual student rankings, and detailed waste logs.
* **Database Backend:** Integrated with MariaDB / MySQL for persistent storage.
